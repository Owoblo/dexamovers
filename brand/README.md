# DEXA Brand Kit

Open [brand-identity.html](/Users/admin/Downloads/dexa/brand/brand-identity.html) for the full brand identity document.

Main asset folders:

- `logos/`: primary logo, reverse logo, one-color logos, and mark-only files
- `social/`: profile avatar and Facebook cover assets
- `.png` files are included for the primary logo, the primary mark, the profile avatar, and the Facebook cover

Recommended quick picks:

- Clothing and embroidery: `logos/dexa-mark-one-color-white.svg` or `logos/dexa-mark-one-color-slate.svg`
- Website and print: `logos/dexa-logo-primary.svg`
- Dark backgrounds: `logos/dexa-logo-reverse.svg`
- Facebook and Instagram profile photo: `social/dexa-avatar.png`
- Facebook cover: `social/dexa-facebook-cover.png`
