# DEXA Brand Kit

Open [brand-identity.html](/Users/owoblo/Downloads/dexamovers/brand/brand-identity.html) for the full brand identity document.

Main asset folders:

- `logos/`: primary logo, reverse logo, one-color logos, and mark-only files
- `social/`: profile avatar and Facebook cover assets
- The primary logo is included as a cropped source image, with SVG support files for website, apparel, and social use.

Recommended quick picks:

- Clothing and embroidery: `logos/dexa-mark-one-color-white.svg` or `logos/dexa-mark-one-color-slate.svg`
- Website and print: `logos/dexa-logo-primary.jpg`
- Dark backgrounds: `logos/dexa-logo-reverse.svg`
- Facebook and Instagram profile photo: `social/dexa-avatar.svg`
- Facebook cover: `social/dexa-facebook-cover.svg`
